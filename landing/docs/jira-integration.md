# Jira Integration Setup

LaneConductor syncs Jira issues to tracks via a bidirectional webhook integration.

## How It Works

```
Jira Issue Created/Updated
         ↓
Jira sends webhook to LC
         ↓
LC receives via /v1/webhooks/jira?token=...
         ↓
LC creates/updates track
         ↓
Worker processes track
         ↓
Worker sends updates back to Jira
```

## Setup Steps

### 1. Generate LaneConductor Webhook Token

1. Open **LaneConductor** dashboard
2. Go to **Project Settings** → **Integrations**
3. Under **Jira Software**, click **Regenerate** next to "Incoming Webhook Token"
4. Copy the full **Jira Webhook URL** displayed below (includes the token)

Example:
```
https://app.laneconductor.com/v1/webhooks/jira?token=abc123def456xyz789
```

### 2. Configure Jira Credentials (Outbound)

In the same **Integrations** section, fill in:

- **Atlassian Domain**: Your Jira domain (e.g., `mycompany.atlassian.net`)
- **Account Email**: Your Jira user email
- **API Token**: Jira API token (see "Get Jira API Token" below)
- **Project Key**: Your Jira project key (e.g., `PROJ`)

### 3. Get Jira API Token

1. Go to **Jira** → Your profile icon → **Account Settings**
2. Left sidebar → **Security** → **API tokens**
3. Click **Create API token**
4. Name it (e.g., "LaneConductor")
5. Copy the token
6. Paste into LaneConductor's **API Token** field

### 4. Create Jira Webhook

1. In **Jira**, go to **System** → **Webhooks**
2. Click **Create a webhook**
3. Fill in:
   - **Name**: `LaneConductor Sync`
   - **URL**: Paste the **Jira Webhook URL** from Step 1 (the full URL with token)
   - **Events**: Select `Issue Created` and `Issue Updated`
4. Click **Save**

### 5. Test It

Create or update a Jira issue:
1. Set label: `ai-task` (or match your project's track pattern)
2. Watch LaneConductor dashboard → track appears automatically
3. Check worker logs:
   ```bash
   tail -f conductor/.sync.log | grep jira
   ```

## Token Clarification

| Token | Generated By | Purpose | Example |
|-------|--------------|---------|---------|
| **Webhook Token** | LaneConductor | Authenticates Jira webhooks to LC | `abc123def456` |
| **API Token** | Jira | Authenticates LC updates back to Jira | `ATATT...` |

## Webhook URL Structure

```
https://app.laneconductor.com/v1/webhooks/jira?token=<WEBHOOK_TOKEN>
         ↑ base URL                              ↑ auto-generated by LC
```

The token is embedded in the URL. When Jira sends a webhook, it calls this URL, and LaneConductor validates the token before processing.

## Troubleshooting

**Webhook not triggering:**
- Verify Jira webhook shows as "Active" (green checkmark)
- Check that the full URL (with token) is correct
- Verify issue has the correct label or project key

**Track not syncing:**
- Check worker logs: `tail -f conductor/.sync.log | grep webhook`
- Ensure Jira credentials (domain, email, API token) are saved in LC

**Updates not going back to Jira:**
- Verify API Token is valid and has permissions
- Check worker logs for hook execution errors
- Ensure workflow.json has hook definitions for desired lanes
