# Track 1098 Specification: Targeted Build Deployment UI & Release Notes Preview

## Objective
Allow operators to select and preview specific versioned build artifacts generated by Track 1097 before triggering deployments to target environments.

## Requirements

### 1. Deployment Modal UI (`WorkersList.jsx` / Deploy Drawer)
- **Deployment Source Radio Toggle**:
  - `Workspace HEAD` (Default): Deploys the latest git commit directly.
  - `Build Artifact`: Shows dropdown list of available builds fetched from `GET /api/projects/:id/builds`.
- **Build Selector Dropdown**:
  - Displays build ID, short Git commit SHA, and creation timestamp.
  - Highlights latest build by default.
- **AI Release Notes Preview**:
  - Displays formatted Markdown changelog of selected build inside an expandable container.
  - Displays list of tracks included in the release.

### 2. Backend Dispatch Update
- `POST /api/projects/:id/deploy`:
  - Accepts optional `buildId`.
  - When `buildId` is supplied, verifies artifact exists in `conductor/builds/<build_id>.json`.
  - Injects environment variables into the deploy execution environment:
    - `CONDUCTOR_BUILD_ID`: The ID of the build (e.g. `build-20260810-163000`)
    - `CONDUCTOR_BUILD_COMMIT`: The Git SHA associated with the build
    - `CONDUCTOR_BUILD_TRACKS`: Comma-separated list of included track IDs

### 3. Deployment History Logging
- Include `buildId` in deployment audit log entries displayed in `DeploymentsPage.jsx`.
